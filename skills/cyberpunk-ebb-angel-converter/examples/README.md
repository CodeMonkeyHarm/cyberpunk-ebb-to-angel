## 复用判定

先看四件事，全部相似才可照搬参数：

1. 鞋筒覆盖高度（短靴 / 及膝 / 过膝 / 裆高 / 护腿）
2. 是否有独立鞋跟、鞋底、鞋头几何
3. 网格数与是否共用几何
4. 源模型在大腿处的原始松量（决定 `push` 还是 `wrap`）

差异项必须在报告第 2 节逐条写出。

## 新增案例的写法

1. 复制 `templates/conversion-report.md` 的字段口径
2. 所有数字从 `analysis/refit_*.json`、`package_*.json`、`chain_*.json` 抄，不手写估算
3. 必须写"遗留问题"与"未验证项"
4. 游戏内结论只能引用用户原话，不得自填
5. 只有满足"几何全绿 + 引用链全解 + 用户确认"才允许升级进 `SKILL.md` 第 6/7 节；否则只在案例里记录
