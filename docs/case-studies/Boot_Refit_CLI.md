# EBBRB → ANGEL 单网格靴类入口

从工作站根目录运行以下命令。`--mesh-entry` 使用从原包中核实的靴子外观所引用的网格。路径可以是解包后的 `.mesh` 相对路径，也可以是 WolvenKit 无法反查路径时使用的数字 `.bin`。`--out` 指向一个新目录。

```powershell
python automation/main.py boot-refit <原始.archive> --mesh-entry <网格条目> --out <新目录>
```

命令按已验证的 Chrissy 配方读原包、保留冻结区域，用 WolvenKit 打包并重新解包校验全部资源。拓扑异常会阻止通过。`report.json` 记录源归档与网格哈希、变更条目、冻结区和往返误差、拓扑及逐点穿透变化。候选归档位于 `packed/`，各次运行的工具日志位于输出目录的 `logs/`。默认使用候选归档名以区分原包。实机替换时备份原包，使用原包同名 archive 和原作者的 `.xl`、`.yaml`。

退出 `0` 表示结构和归档校验通过。贴合、材质和实机观感仍需单独验证。命令按位置转换保留原材质引用。Melinda 原包的六个错误贴图路径仍需应用既有的独立修复，正式入口本次重建的产物与历史纯几何候选一致。
